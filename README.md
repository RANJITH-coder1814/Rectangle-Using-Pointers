# Rectangle Class in C++

This repository contains a simple C++ program that demonstrates **Object-Oriented Programming (OOP)** concepts using a `Rectangle` class. The program calculates the **area** and **perimeter** of a rectangle using **dynamic memory allocation (pointers)**.

## 📌 Features
- Uses a C++ class (`Rectangle`)
- Demonstrates object creation using `new`
- Calculates:
  - Area of a rectangle
  - Perimeter of a rectangle
- Beginner-friendly and easy to understand

## 🧠 Concepts Used
- Classes and Objects
- Pointers
- Dynamic Memory Allocation
- Member Functions
- Basic C++ syntax

## 🧾 Code Overview
The `Rectangle` class contains:
- Data members: `length`, `breadth`
- Member functions:
  - `area()` – returns area of the rectangle
  - `perimeter()` – returns perimeter of the rectangle

An object is created dynamically using a pointer in `main()`.
